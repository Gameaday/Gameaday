# Home Lab Service Catalog

This document catalogs potential services for the home lab, detailing their purpose, requirements, benefits, and implementation considerations.

## Service Evaluation Framework

Before adding any service, apply the **Invisible Value Test**:
1. What specific family time/money does this save? (Be concrete)
2. What recurring cost does this eliminate? (Name the subscription service)
3. What privacy risk does this reduce? (What data stays home that previously left?)
4. What reliability problem does this solve? (What current frustration does this fix?)
5. What's the monitoring overhead? (How much admin time to keep it working?)
6. What's the failure impact? (If this breaks tomorrow, what family disruption occurs?)
7. The "So What?" Test: If we deployed this, what would family members notice as better?

And the **Headless Suitability Questions**:
- Does it run autonomously with <5min/month maintenance?
- Does it improve something family actually uses daily/weekly?
- Does it enhance privacy without reducing convenience?
- Is it cheaper than the alternative over 2 years? (Factor in time, not just dollars)
- Can we verify it's working without logging in? (Automated health checks with simple alerts)
